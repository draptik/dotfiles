# Wayscribar

- URL: <https://wayscriber.com>
- ZoomIt tool for Wayland

## Installation

- `yay -S wayscriber-bin`
- `systemctl --user enable --now wayscriber.service`

## Usage

- CLI: `wayscribar --daemon-toggle`
- In Sway, I bound the toggle to `mod+Shift+d` (see [`07-hotkeys.conf`](../sway/sway.d/07_hotkeys.conf) for details).

## Configuration

- Currently using defaults.
- Official docs for configuration: <https://wayscriber.com/docs/configuration/config-file.html>
